# Intelligent Text Compression and Summarization Tool

A small C++ student project. You enter some text, and the program compresses it and summarizes it.
It has two versions that share the same C++ code:

- a **command-line program**, and
- a **web page** that runs the C++ code in the browser using WebAssembly.

The algorithms use the C++ standard library. The browser version also uses Emscripten to connect the C++ code to the webpage.

## How it works

**Compression: run-length encoding (RLE).**
A character that repeats is written once, followed by its count. Other characters stay as they are.

```
"aaabbbbc"  ->  "a3b4c"
```

**Summarization: word-frequency scoring.**
1. Split the text into sentences (`.`, `!`, `?`).
2. Count how often each word appears (words shorter than 4 letters are ignored).
3. Score each sentence by adding up the counts of its words.
4. Keep the 2 highest-scoring sentences, in their original order.

## Project files

| File | What it does |
|---|---|
| `core.h`, `core.cpp` | The compression and summarization code (shared by both versions) |
| `main.cpp` | The command-line program |
| `wasm_bridge.cpp` | A small bridge that lets the web page call the C++ code |
| `docs/index.html`, `docs/style.css`, `docs/app.js` | The web page (only the interface: it collects text and shows results) |
| `docs/textool.js`, `docs/textool.wasm` | The C++ code compiled to WebAssembly (generated by `build.sh`) |
| `build.sh` | Builds both versions |

## Command-line version

Needs a C++ compiler such as `g++`.

```
g++ -std=c++11 -o textool main.cpp core.cpp
./textool
```

On Windows (MinGW), run `textool.exe` instead of `./textool`.

Type or paste your text, then press Enter on an empty line to finish.

## Web version

The compiled files are already in `docs/`, so you can run the page without installing anything extra.
Browsers do not load `.wasm` files when you double-click `index.html`, so use a small local server:

```
python3 -m http.server --directory docs 8000
```

Then open <http://localhost:8000> in your browser.

The page lets you enter text, then shows the compressed text, the original and compressed
character counts, the percentage saved, and a summary of up to two sentences.
If the box is empty, it shows a message instead.

### Rebuilding the WebAssembly files

Only needed if you change the C++ code. This needs [Emscripten](https://emscripten.org/) (`emcc`).

```
./build.sh
```

This builds the command-line program and, if `emcc` is found, the files in `docs/`.
(The files in `docs/` were built with Emscripten 3.1.6.)

### Publishing with GitHub Pages

The website files are in the `docs/` folder. In the GitHub repository, open
**Settings -> Pages**, choose **Deploy from a branch**, select your main branch and the
`/docs` folder, then save. GitHub shows the live link once it is deployed.

## Example

Input:

```
Wooooow!!! That was sooooo cooool. Aaaaaaand the crowd went wiiiiild. Nothing beats a goooood show.
```

Command-line output:

```
Compression (run-length encoding)
Wo5w!3 That was so5 co4l. Aa6nd the crowd went wi5ld. Nothing beats a go5d show. 
Original length:   100 characters
Compressed length: 81 characters
Space saved:       19%

--- Summary (top 2 sentences) ---
Aaaaaaand the crowd went wiiiiild. Nothing beats a goooood show. 
```

The command-line program adds one space after each line you type, so it counts 100 characters here.
The web page counts exactly what is in the text box (99 characters for the same text, 80 after compression).

## Limitations

- RLE only helps when characters repeat. Normal English text saves little or nothing.
- The program only compresses. It has no decompression, and digits in the text would make decoding ambiguous.
- Sentences are split at every `.`, `!` or `?`, so things like `Dr.` or `3.5` count as sentence ends.
- Longer sentences tend to score higher because the score is a plain sum.
